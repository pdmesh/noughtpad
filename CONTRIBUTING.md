# Contributing

Thanks for your interest in Noughtpad.

## Before you start

- **Bugs and ideas:** open an [issue](https://github.com/pdmesh/noughtpad/issues). For a bug, include your version (shown in Settings) and steps to reproduce.
- **Code:** for anything bigger than a small fix, open an issue first so we can agree on the approach before you spend time on it.
- **Setting up:** the [README](README.md#development) covers prerequisites, running the app, the sample notebook and the tests. Before opening a pull request, run `cargo fmt --all`, `cargo test --workspace`, `pnpm typecheck` and `pnpm test`.
- **Security problems:** please don't open an issue; see [SECURITY.md](SECURITY.md).
