This page takes you from nothing to your first saved note. It takes about five minutes.

## 1. Download

Go to the [download page](/download/) and get the file for your computer:

- **Mac** (Apple Silicon, M1 or later): the file ending in `.dmg`.
- **Windows**: the file ending in `setup.exe`.
- **Linux**: the `.AppImage`, `.deb` or `.rpm`.

## 2. Install

**Mac.** Open the `.dmg` and drag Noughtpad into your Applications folder, then open it from there.

<h3 id="first-open-mac">Opening it on a Mac the first time</h3>

While Noughtpad is in beta, Apple hasn't notarised it yet, so macOS asks you to confirm it once. This step goes away after the beta.

1. Click **Done** on the message that appears.
2. Open **System Settings**, then **Privacy & Security**.
3. Scroll down to **Security** and click **Open Anyway** next to the line about Noughtpad.
4. Enter your password if asked, and click **Open Anyway** again.

You only do this once. Updates from inside the app open straight away.

**Windows.** Run the installer. During the beta, Windows may show a blue "Windows protected your PC" box. Click **More info**, then **Run anyway**.

**Linux.** Make the AppImage executable and open it, or install the `.deb` or `.rpm` package.

## 3. Choose where your notes live

The first time Noughtpad opens, it asks where to keep your notes. You have two choices:

- **Start in Documents/Noughtpad.** A new folder called Noughtpad in your Documents folder.
- **Choose another folder.** Any folder you like. It can be empty, or it can already hold Markdown files, such as an Obsidian vault.

> **Tip for Mac users.** If you keep your notes outside Documents, Desktop, Downloads and iCloud Drive (for example in a folder called Noughtpad in your home folder), Noughtpad starts faster after each update. [Why](/guide/common-problems/#slow-first-launch)

You can switch folders later in **Settings → Notes folder**.

## 4. Write

You'll see an empty page with a blinking cursor. Start typing. That's it: there's no Save button, because every change is saved as you go.

A few things to try:

- Type `# ` at the start of a line to make a heading.
- Type `- [ ] ` to make a checkbox.
- Press **⌘N** (Ctrl+N on Windows and Linux) to start another note.
- Move the pointer to the left edge of the window to see the sidebar, with **All notes**, **Journal**, **Ideas over time** and **Chat**.

## 5. Capture from anywhere

Press **⌘⇧Space** (Ctrl+Shift+Space on Windows and Linux) while you're in any other app. Noughtpad comes to the front on a new, empty note.

On a Mac, closing the window doesn't quit Noughtpad; it keeps running in the background so this shortcut is instant. Use **⌘Q** to quit. If you'd like it ready every time you start your computer, turn on **Settings → Start-up → Open at login**.
