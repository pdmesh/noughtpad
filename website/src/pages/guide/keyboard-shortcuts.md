On a Mac, **⌘** is the Command key and **⇧** is Shift. On Windows and Linux, use **Ctrl** where a Mac uses **⌘**.

## Everyday

| Mac | Windows and Linux | What it does |
|---|---|---|
| ⌘⇧Space | Ctrl+Shift+Space | New note from any app (quick capture) |
| ⌘N | Ctrl+N | New note |
| ⌘K | Ctrl+K | Search and commands |
| ⌘J | Ctrl+J | Show or hide related notes |
| ⌘L | Ctrl+L | Chat |
| ⌘\\ | Ctrl+\\ | Show or hide the sidebar and toolbar |
| ⌘, | | Settings (Mac menu) |
| Esc | Esc | Close search, or the related-notes panel |

## Writing

| Mac | Windows and Linux | What it does |
|---|---|---|
| ⌘⇧V | Ctrl+Shift+V | Paste as plain text |
| ⌘C | Ctrl+C | Copy as Markdown and formatted text |
| ⌘Z | Ctrl+Z | Undo |

## In the search box

| Key | What it does |
|---|---|
| ↑ ↓ | Move through results |
| Enter | Open the selected result or run the command |
| Esc | Close |

## On a Mac: the menu bar

Every command is also in the menu bar: **File → New Note**, **View → Show or Hide Sidebar**, **Search Notes**, **Related Notes**, **Chat**, and a **Go** menu with every page. **Noughtpad → Check for Updates…** looks for a new version.

Closing the window with **⌘W** or the red button keeps Noughtpad running, so quick capture is instant. **⌘Q** quits.
